# Manifesto

Version 1.0.0

The few rules {{NAME}} does not bend. Each has an id `T<n>` that roadmap phases and plans
cite. Changing one is a decision (a `DEC` row) approved at a phase close.

- **T1 — Tests are the contract.** A phase is described by acceptance tests written before
  the code. They are locked and are not edited to make code pass.
- **T2 — Reuse before build.** New work calls what already exists instead of copying it.
