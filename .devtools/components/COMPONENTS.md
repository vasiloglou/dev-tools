# Components

What dev-tools' own code can already do, by capability. Search it before writing new code,
from the repository root:

```bash
python3 plugins/dvt-milestone/skills/components/scripts/components_index.py search <what you need, in plain words>
```

The command runs the built copy of the index script, which reads its settings from
`.devtools/components_index.settings.json` (`.devtools/project.md`, R0.3 of the
component-index milestone). Each entry is written by hand (`does`, `verbs`, `status`,
`modules`, `tests`). The `uses` / `used_by` lines and the verbs list are generated by the
same script's `write`. The shipped scripts import nothing from each other, so no entry has
a `uses` line; where one script runs another, the subsystems at the end say so.
